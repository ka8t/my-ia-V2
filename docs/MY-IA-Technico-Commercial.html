1 Vue d'ensemble

MY-IA est une solution d'IA conversationnelle privée avec RAG (Retrieval-Augmented Generation), déployable on-premise ou sur infrastructure dédiée.

Proposition de valeur

Souveraineté
100% des données restent sur votre infrastructure. Aucun appel vers des API cloud.
RGPD Natif
Audit complet, droit à l'oubli, export des données. Conformité par conception.
Coût Maîtrisé
Pas d'abonnement par utilisateur. Coût = infrastructure uniquement.

3.2 Gestion documentaire

FormatExtensionsTraitement
PDF.pdfExtraction texte + OCR si image
Office.docx, .xlsx, .pptxParsing natif
Images.png, .jpg, .tiff, .webpOCR (Tesseract)
Texte.txt, .md, .html, .csv, .jsonExtraction directe
Email.eml, .msgParsing headers + body
  • Chunking sémantique — Découpage intelligent par paragraphes/sections
  • Déduplication — Hash SHA-256, pas de doublons
  • Versioning — Historique des modifications avec restauration
  • Visibilité — Public (partagé) ou privé (personnel)
  • Quotas — Limites de stockage par utilisateur
  • Upload async — Progression temps réel, indexation en arrière-plan

4 Sécurité & Conformité

Authentification

JWTAccess tokens (15 min) + Refresh tokens (7 jours)
OAuth 2.0Google, GitHub (extensible)
Vérification emailDouble opt-in avec tokens signés
Reset passwordTokens à usage unique, expiration 1h
Auto-logoutDéconnexion après 30 min d'inactivité

Contrôle d'accès (RBAC)

RôlePermissions
AdminAccès complet (config, users, audit, all features)
ValidateurApprobation contenu, modération
ContributeurUpload documents, gestion corpus
UtilisateurChat, documents personnels uniquement

Politique mot de passe

  • Longueur minimale configurable (défaut : 12)
  • Exigences : majuscule, minuscule, chiffre, caractère spécial
  • Expiration automatique (configurable)
  • Historique (empêche réutilisation des N derniers)
  • Hachage : Argon2id (via pwdlib)

Audit & Traçabilité

  • Journal complet : qui, quoi, quand, IP, user-agent
  • Actions tracées : login, logout, CRUD, config changes, accès documents
  • Export : CSV, JSON
  • Rétention configurable
  • Alertes sur actions sensibles

Conformité RGPD

✓
Privacy by Design
• Données 100% locales
• Droit à l'oubli (suppression utilisateur + données)
• Export des données personnelles
• Audit trail complet
• Pas de tracking, pas de télémétrie

5 Intégration & API

API REST

  • Documentation : OpenAPI 3.0 auto-générée (/docs, /redoc)
  • Authentification : Bearer JWT ou API Key
  • Format : JSON (application/json)
  • Pagination : offset/limit avec total_count
  • Erreurs : Format standardisé {detail, code, field}

Endpoints principaux

Webhooks (prévu)

Notifications sur événements : nouveau document, conversation terminée, alerte sécurité.

Intégrations possibles

  • SSO : SAML, LDAP (via extension OAuth)
  • Monitoring : Prometheus, Grafana
  • Logs : ELK, Loki (export JSON)
  • Stockage : S3-compatible (prévu)

7 Déploiement

Installation rapide

git clone https://github.com/your-repo/my-ia.git
cd my-ia
cp .env.example .env
# Configurer les credentials PostgreSQL dans .env
docker-compose up -d

Modes de déploiement

ModeDescriptionCas d'usage
StandaloneDocker Compose sur une machinePME, usage personnel
VPS dédiéServeur cloud isoléÉquipes distantes
On-premiseInfrastructure interneGrandes organisations, secteur public
KubernetesOrchestration avancée (prévu)Scalabilité horizontale

Sauvegarde

  • PostgreSQL : pg_dump quotidien
  • ChromaDB : Export des collections
  • Fichiers : Répertoire /data/storage
  • Configuration : Export via API /admin/config/export

Mise à jour

git pull origin main
docker-compose pull
docker-compose up -d --build
# Migrations automatiques au démarrage
