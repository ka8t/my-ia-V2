1. Objectif

Creer un systeme de pagination mutualise pour tous les tableaux de l'admin, avec :

  • Affichage en haut ET en bas des tableaux
  • Toutes les fonctionnalites attendues d'une pagination moderne
  • Adaptation automatique au module appelant
  • Selecteur de taille de page (10, 25, 50, 100)
  • Event delegation (pas de callbacks globaux)

2.2 PaginationMixin Existant

UI-SHARED/js/mixins/pagination.js

Points forts

  • Etat pagination (currentPage, pageSize, total, totalPages)
  • Fenetre glissante de pages
  • Methodes goToPage(), resetPagination(), updatePagination()

Limitations

  • Pagination uniquement en bas
  • Pas de selecteur de taille de page
  • HTML inline (pas de templates)
  • Textes non traduits (hardcodes)

3. Solution Proposee

3.1 Nouveau Composant TablePagination

UI-SHARED/js/components/table-pagination.js

const TablePagination = {
    render(containerId, options) { ... },

    defaultOptions: {
        currentPage: 1,
        pageSize: 25,
        total: 0,
        pageSizes: [10, 25, 50, 100],
        showPageSizeSelector: true,
        showInfo: true,

    }
}

3.3 Event Delegation

Les boutons utilisent data-page="X" au lieu de onclick="Module.goToPage(X)"

Un seul listener sur le conteneur capture tous les clics.

Pas besoin d'exposer le module globalement.
