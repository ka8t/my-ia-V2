Objectif & Contexte — Section 1

⬆ Sommaire

Problème actuel

Le système MY-IA utilise actuellement un style de réponse unique, défini par le mode de conversation (chatbot ou assistant) choisi manuellement lors de la création de la conversation.

⚠️ Limitation : Un utilisateur qui dit "Bonjour !" reçoit une réponse formelle si le mode assistant est actif, ce qui crée une expérience utilisateur déconnectée.

Solution proposée

Détecter automatiquement la nature de chaque message pour adapter le style de réponse en temps réel, tout en conservant le RAG actif pour les réponses contextualisées.

😊 Mode Chatbot
Style conversationnel, amical, décontracté.
Pour : salutations, bavardage, questions simples, feedback.
💼 Mode Assistant
Style formel, structuré, professionnel.
Pour : analyses, explications techniques, tâches, recherches.

Principes clés

  • RAG toujours actif : Le contexte documentaire est recherché quel que soit le mode
  • Détection par message : Chaque message est analysé indépendamment
  • Override possible : L'utilisateur peut forcer un mode via toggle ou préfixe
  • Transparence : Le mode utilisé est retourné dans la réponse API

Définition des Modes — Section 2

⬆ Sommaire

Mode Chatbot (conversationnel)

💬 Ton : Amical, décontracté, empathique
Format : Réponses courtes, naturelles, pas de listes structurées
Ponctuation : Points d'exclamation, questions rhétoriques autorisés

Exemples de prompts utilisateur :

  • "Bonjour !"
  • "Ça va ?"
  • "Merci beaucoup"
  • "C'est quoi ton nom ?"
  • "T'es là ?"

Exemple de réponse chatbot :

Bonjour ! Je vais bien, merci de demander. Comment puis-je t'aider aujourd'hui ?

Mode Assistant (formel)

📋 Ton : Professionnel, précis, factuel
Format : Réponses structurées, listes, titres si nécessaire
Contenu : Basé sur les sources, citations explicites

Exemples de prompts utilisateur :

  • "Analyse les tendances du marché informatique"
  • "Compare les deux approches techniques"
  • "Explique en détail le fonctionnement de X"
  • "Quels sont les KPIs du projet Y ?"
  • "Résume le document sur la sécurité"

Exemple de réponse assistant :

Selon les documents disponibles, voici l'analyse des tendances : **1. Croissance du secteur** - Le marché IT progresse de 8% par an (Source: rapport_2025.pdf) - Les compétences cloud sont les plus demandées **2. Enjeux identifiés** - Pénurie de talents qualifiés - Transformation digitale accélérée

Mécanisme existant : Mode RAG

Il existe déjà une détection automatique pour le mode RAG (fast vs full) basée sur la complexité de la requête. Ce mécanisme peut servir de modèle pour la détection du style de réponse.

DÉTECTION EXISTANTE : RAG MODE (rag_config.py:189-248)
def detect_query_complexity(query: str) -> str: words = len(query.split()) # Mots-clés indiquant une question complexe complex_keywords = ["détaille", "explique", "compare", "analyse", "pourquoi", "comment fonctionne"] if words < 10: return "fast" # Questions courtes → mode rapide elif words >= 15 or any(kw in query.lower() for kw in complex_keywords): return "full" # Questions longues/complexes → mode complet else: return "fast" # Défaut

Algorithme de Détection — Section 4

⬆ Sommaire

Critères de détection

→ Mode Chatbot

PatternScore
Salutation (bonjour, salut, hello, hi)+50
Émojis présents+30
Question < 5 mots+20
Mots informels (ok, cool, super, merci)+15
Points d'exclamation multiples+10
Tutoiement détecté+10

→ Mode Assistant

PatternScore
Verbes d'analyse (analyse, compare, explique)+40
Question > 15 mots+30
Mots techniques détectés+25
Demande de liste/tableau/code+20
Référence document ("selon", "dans le")+15
Vouvoiement détecté+10

Algorithme proposé

FONCTION : detect_response_style(query: str) -> str
def detect_response_style(query: str) -> str: """ Détecte le style de réponse adapté à la requête. Returns: "chatbot" ou "assistant" """ query_lower = query.lower().strip() words = query_lower.split() word_count = len(words) chatbot_score = 0 assistant_score = 0 # === Patterns Chatbot === GREETINGS = {"bonjour", "salut", "hello", "hi", "hey", "coucou", "bonsoir"} INFORMAL = {"ok", "cool", "super", "merci", "thanks", "top", "nickel", "parfait"} if words and words[0] in GREETINGS: chatbot_score += 50 if any(w in INFORMAL for w in words): chatbot_score += 15 if any(c in query for c in "😀👍❤️🎉"): # Emojis chatbot_score += 30 if word_count < 5: chatbot_score += 20 if query.count("!") >= 2: chatbot_score += 10 if any(w in words for w in ["tu", "toi", "t'es"]): chatbot_score += 10 # === Patterns Assistant === ANALYSIS_VERBS = {"analyse", "compare", "explique", "détaille", "résume", "liste", "décris", "évalue", "synthétise"} TECHNICAL = {"api", "code", "fonction", "erreur", "bug", "config", "base de données", "serveur", "déploiement", "architecture"} if any(v in query_lower for v in ANALYSIS_VERBS): assistant_score += 40 if word_count > 15: assistant_score += 30 if any(t in query_lower for t in TECHNICAL): assistant_score += 25 if any(p in query_lower for p in ["donne-moi la liste", "fais un tableau", "montre le code"]): assistant_score += 20 if any(p in query_lower for p in ["selon le document", "dans le fichier", "d'après"]): assistant_score += 15 if any(w in words for w in ["vous", "votre", "pourriez"]): assistant_score += 10 # === Décision === # Seuil de différence pour éviter l'ambiguité if chatbot_score > assistant_score + 10: return "chatbot" elif assistant_score > chatbot_score + 10: return "assistant" else: # En cas d'ambiguité, préférer assistant (plus sûr) return "assistant"

Cas particuliers

Requête Score Chatbot Score Assistant Résultat
"Bonjour !" 50 + 10 = 60 0 chatbot
"Salut, peux-tu m'expliquer comment fonctionne l'API ?" 50 + 10 = 60 40 + 25 = 65 assistant (ambigu → assistant)
"Analyse les performances du serveur de production" 0 40 + 25 = 65 assistant
"Merci beaucoup !" 15 + 20 + 10 = 45 0 chatbot
"C'est quoi ?" 20 0 chatbot

Interface Utilisateur — Section 6

⬆ Sommaire

Override manuel

L'utilisateur peut forcer un style de deux manières :

🔘 Toggle UI
Bouton dans la barre d'input pour basculer entre Auto / Chatbot / Assistant. La valeur est envoyée dans response_style.
⌨️ Préfixes
/chat : Force mode chatbot
/assistant ou /pro : Force mode assistant
Le préfixe est retiré avant envoi au LLM.
