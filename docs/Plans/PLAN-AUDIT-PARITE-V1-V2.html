1.1.4 Cas concret : bug d'indexation xlsx

🚨
Découvert pendant l'audit (session 2026-05-07) — Upload xlsx en V2 : indexation échec silencieux avec partition_xlsx() is not available because one or more dependencies are not installed.

Cause : unstructured==0.15.13 est installé sans extras. Le parsing xlsx requiert unstructured[xlsx] qui pull networkx. La même ligne existe en V1 (même bug présent ?). En V2, le bug est aggravé par l'absence de feedback UI : la ligne du tableau Documents reste sur "Indexation…" infiniment (cf. Axe 3 § "Documents").

Action retenue : ajouter unstructured[xlsx] à requirements.txt (plan de correction séparé, post-audit).
