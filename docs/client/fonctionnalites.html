Chat intelligent — Section 1

Le cœur de MY-IA : posez vos questions en langage naturel et obtenez des réponses précises basées sur les documents de votre entreprise.

Capacités principales

🔍 Recherche contextuelle
MY-IA analyse votre question, recherche dans tous vos documents et synthétise une réponse pertinente. Il comprend le contexte et les nuances.
📝 Réponses sourcées
Chaque réponse indique les documents utilisés avec le numéro de page. Cliquez sur une source pour vérifier l'information originale.
🔁 Mémoire conversationnelle
MY-IA se souvient du contexte de la conversation. Posez des questions de suivi comme "Et pour les cadres ?" ou "Peux-tu détailler le point 2 ?".
🎯 Réponses adaptées
Demandez le format qui vous convient : liste à puces, tableau, résumé court ou explication détaillée. MY-IA s'adapte à vos besoins.

Types de questions supportées

TypeExempleCe que MY-IA fait
Recherche factuelle "Quelle est la durée du préavis pour une démission ?" Trouve la réponse exacte dans les documents RH
Synthèse "Résume les points clés du rapport annuel 2025" Lit le document et en extrait l'essentiel
Comparaison "Compare les offres Standard et Premium" Analyse plusieurs documents et présente les différences
Explication "Explique-moi le processus de validation des congés" Détaille les étapes de manière pédagogique
Aide à la rédaction "Rédige un email de relance pour un devis" Génère un texte en s'inspirant des modèles existants

Astuces pour de meilleures réponses

✅ Bonnes pratiques

  • Soyez précis — "Quelle est la procédure RH pour les congés maladie ?" au lieu de "congés"
  • Donnez du contexte — "Dans le rapport Q3 2025, quels sont les chiffres de ventes ?"
  • Demandez un format — "Liste les étapes sous forme de puces numérotées"
  • Précisez la longueur — "Résume en 3 points maximum"

❌ À éviter

  • Questions vagues — "Parle-moi des ventes" (trop général)
  • Plusieurs sujets — "Congés et salaires et formations" (une question à la fois)
  • Suppositions — "Le document X dit que..." (laissez MY-IA chercher)
  • Acronymes non définis — Précisez ce que signifie un sigle spécifique

Gestion des conversations — Section 2

Organisez vos échanges avec MY-IA pour retrouver facilement vos informations et reprendre une discussion où vous l'avez laissée.

Interface des conversations

Le panneau latéral gauche affiche toutes vos conversations :

📅 Historique complet
Toutes vos conversations sont sauvegardées automatiquement. Retrouvez-les par date ou par nom.
🔍 Recherche rapide
Utilisez la barre de recherche pour trouver une conversation par mot-clé.
🏷️ Titres automatiques
MY-IA nomme automatiquement chaque conversation selon son sujet.

Actions sur les conversations

ActionComment faireDétails
+ Nouveau Cliquez sur le bouton + Nouveau Démarre une conversation vierge sans contexte précédent
✏️ Renommer Cliquez sur le titre de la conversation Donnez un nom explicite pour retrouver facilement
🗑️ Supprimer Survolez et cliquez sur la corbeille Suppression définitive (demande de confirmation)
📤 Exporter Menu → Exporter Téléchargez la conversation au format texte

Continuer une conversation

Pour reprendre une discussion :

1. Ouvrez le panneau latéral
Cliquez sur l'icône menu ou utilisez le raccourci
2. Sélectionnez une conversation
Les plus récentes apparaissent en haut
3. Continuez votre échange
MY-IA se souvient du contexte précédent
4. Posez votre nouvelle question
Vous pouvez faire référence aux échanges passés
💡 Astuce : Créez une nouvelle conversation pour chaque sujet différent. Cela aide MY-IA à rester focalisé et facilite la recherche ultérieure.

Mes documents — Section 3

Uploadez vos propres documents pour que MY-IA puisse les utiliser dans ses réponses. Vos documents personnels sont privés et ne sont pas visibles par les autres utilisateurs.

Formats acceptés

📑 Documents texte
PDF — Rapports, manuels, présentations
Word (.docx) — Documents Office
Texte (.txt) — Fichiers texte brut
Markdown (.md) — Documentation technique
📊 Données structurées
Excel (.xlsx) — Tableaux, listes, données
CSV — Exports de bases de données
MY-IA peut analyser les lignes et colonnes
🎬 Présentations
PowerPoint (.pptx) — Slides et présentations
MY-IA extrait le texte de chaque slide

Ajouter un document

1. Accédez à "Mes documents"
Cliquez sur l'icône 📄 dans le menu latéral ou en haut de l'écran
2. Cliquez sur "Ajouter" ou glissez-déposez
Vous pouvez ajouter plusieurs fichiers d'un coup (jusqu'à 10 fichiers)
3. Attendez le traitement
MY-IA analyse et indexe votre document. La barre de progression indique l'avancement.
4. Utilisez votre document
Une fois le traitement terminé, posez vos questions dans le chat !

Gérer vos documents

ActionDescription
👁️ VoirOuvrez un aperçu du document dans le navigateur
⬇️ TéléchargerRécupérez le fichier original
🗑️ SupprimerRetire le document de votre espace (irréversible)
📊 DétailsVoir le nombre de pages, la taille, la date d'ajout

Documents système vs. personnels

📚 Documents système

  • Gérés par l'administrateur
  • Accessibles à tous les utilisateurs
  • Documents officiels de l'entreprise
  • Procédures, règlements, catalogues

📁 Documents personnels

  • Uploadés par vous
  • Privés — personne d'autre ne les voit
  • Quota limité (voir vos paramètres)
  • Notes, brouillons, documents de travail
⚠️ Limite de taille : Par défaut, les fichiers sont limités à 50 Mo. Contactez votre administrateur si vous avez besoin de plus.

Mode vocal — Section 4

Parlez à MY-IA au lieu de taper. Idéal quand vous avez les mains occupées ou pour les questions longues.

Dicter votre question

1. Cliquez sur le micro 🎤
Le bouton se trouve à droite de la zone de saisie
2. Autorisez l'accès au micro
Le navigateur vous demande la permission (première fois uniquement)
3. Parlez clairement
Votre texte s'affiche en temps réel dans la zone de saisie
4. Cliquez à nouveau pour arrêter
Ou attendez quelques secondes de silence

Écouter les réponses

MY-IA peut vous lire ses réponses à voix haute :

OptionDescriptionOù l'activer
Lecture automatique Chaque réponse est lue automatiquement Paramètres > Voix > Lecture auto
Lecture à la demande Cliquez sur 🔊 sous une réponse pour l'écouter Activé par défaut
Choix de la voix Sélectionnez la voix qui vous convient Paramètres > Voix > Voix de synthèse
Vitesse de lecture Accélérez ou ralentissez la lecture Paramètres > Voix > Vitesse
💡 Compatibilité : Le mode vocal fonctionne sur Chrome, Edge et Safari. Firefox a un support limité. Utilisez un micro de qualité pour de meilleurs résultats.

Modes de conversation — Section 5

Les modes adaptent le comportement de MY-IA selon le contexte. Chaque mode peut avoir des documents spécifiques et un style de réponse personnalisé.

Modes disponibles

Votre administrateur peut configurer différents modes. Exemples courants :

💼 Mode RH
Questions sur les congés, la paie, les procédures RH. Accès aux documents du service RH uniquement.
📊 Mode Commercial
Recherche de prix, disponibilité produits, argumentaires. Accès aux catalogues et fiches produits.
⚙️ Mode Technique
Documentation technique, procédures de maintenance. Réponses plus détaillées et techniques.
🎓 Mode Formation
Support de cours, quiz, explications pédagogiques. Style plus didactique.

Changer de mode

1. Ouvrez le sélecteur de mode
Cliquez sur le nom du mode actuel en haut de l'écran
2. Choisissez un nouveau mode
La liste affiche tous les modes disponibles pour vous
3. Confirmez le changement
Une nouvelle conversation démarre avec le mode sélectionné
💡 Mode par défaut : Si vous ne choisissez pas de mode, MY-IA utilise le mode "Général" qui a accès à tous les documents publics.
