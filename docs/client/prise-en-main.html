Bienvenue sur MY-IA

MY-IA est votre assistant intelligent au quotidien. Imaginez avoir un collègue qui a lu tous les documents de votre entreprise et peut vous répondre instantanément. C'est exactement ce que fait MY-IA.

Ce que vous pouvez faire avec MY-IA

❓ Poser des questions
"Quelle est la procédure pour poser des congés ?"
"Qui est le responsable du projet Alpha ?"
"Quel est le budget prévisionnel 2026 ?"
📝 Résumer des documents
"Résume-moi le rapport trimestriel"
"Quels sont les points clés du contrat client X ?"
"Fais-moi une synthèse des ventes de janvier"
🔍 Rechercher des informations
"Trouve tous les documents sur le projet Beta"
"Quelles sont nos conditions de garantie ?"
"Montre-moi les tarifs actuels"
📊 Analyser des données
"Compare les ventes Q1 et Q2"
"Quelle évolution des effectifs depuis 2024 ?"
"Identifie les tendances dans ce rapport"
💡 Pas besoin d'être technique : Posez vos questions comme vous le feriez à un collègue. MY-IA comprend le langage naturel.
1

Étape 1 : Se connecter

Accéder à MY-IA

Ouvrez votre navigateur web (Chrome, Firefox, Safari, Edge) et saisissez l'adresse fournie par votre administrateur :

https://myia.votre-entreprise.com
📱 Mobile : MY-IA fonctionne aussi sur smartphone et tablette. L'interface s'adapte automatiquement à votre écran.

Écran de connexion

Vous arrivez sur la page de connexion. Remplissez les champs suivants :

ChampQue saisirExemple
Email Votre adresse email professionnelle marie.dupont@entreprise.com
Mot de passe Le mot de passe fourni par votre administrateur ou choisi lors de l'inscription ********

Options de connexion

  • Se souvenir de moi — Cochez cette case pour rester connecté sur cet appareil (ne le faites pas sur un ordinateur partagé)
  • Mot de passe oublié — Cliquez sur ce lien pour recevoir un email de réinitialisation

Première connexion

Si c'est votre première connexion, vous devrez peut-être :

  1. Changer votre mot de passe temporaire — Choisissez un mot de passe personnel et sécurisé
  2. Compléter votre profil — Ajoutez votre nom et prénom
  3. Choisir vos préférences — Langue, thème clair/sombre
🔒 Sécurité : Utilisez un mot de passe unique d'au moins 8 caractères avec majuscules, chiffres et caractères spéciaux.
2

Étape 2 : Découvrir l'interface

Une fois connecté, vous arrivez sur l'interface principale de MY-IA. Prenons quelques instants pour la découvrir.

Les zones de l'écran

ZonePositionRôle
☰ Menu latéral Gauche Accès à vos conversations, documents et paramètres
💬 Zone de chat Centre Vos échanges avec MY-IA s'affichent ici
✏️ Zone de saisie Bas C'est ici que vous tapez vos questions
👤 Profil Haut droite Accès à votre compte et déconnexion

Le menu latéral en détail

➕ Nouvelle conversation
Démarre une nouvelle discussion. Utile pour changer de sujet ou repartir de zéro.
📁 Historique
Liste de vos conversations précédentes. Cliquez sur une conversation pour la reprendre.
📄 Mes documents
Vos fichiers personnels. Vous pouvez y ajouter des documents pour que MY-IA les utilise.
⚙️ Paramètres
Personnalisez MY-IA : thème, langue, préférences de réponse.

La zone de saisie

En bas de l'écran, vous trouvez la zone de saisie avec plusieurs éléments :

  • Champ de texte — Tapez votre question ici
  • 🎤 Micro — Dictez votre question au lieu de la taper
  • 📎 Pièce jointe — Joignez un document à votre question
  • ➡️ Envoyer — Envoyez votre question (ou appuyez sur Entrée)
3

Étape 3 : Poser votre première question

C'est le moment de tester MY-IA ! Suivez ces étapes simples :

1. Cliquez dans la zone de saisie
Le curseur clignote, vous pouvez taper.
2. Tapez votre question
Par exemple : "Bonjour, peux-tu te présenter ?"
3. Appuyez sur Entrée
Ou cliquez sur le bouton d'envoi ➡️
4. Attendez la réponse
MY-IA réfléchit... La réponse s'affiche progressivement.
5. Lisez et continuez
Posez des questions de suivi ou changez de sujet.

Exemples de premières questions

TypeExemple de question
Simple "Bonjour, comment ça marche ?"
Information "Quels sont les horaires d'ouverture du service client ?"
Procédure "Comment faire une demande de remboursement ?"
Recherche "Trouve-moi les documents sur la politique voyage"

Comprendre la réponse

Chaque réponse de MY-IA contient plusieurs éléments :

📝 Le texte de réponse
La réponse à votre question, rédigée de manière claire et structurée.
📚 Les sources
Les documents utilisés pour construire la réponse. Cliquez dessus pour vérifier l'information.
👍 👎 Évaluation
Notez la réponse pour aider à améliorer MY-IA.
📋 Copier
Copiez la réponse pour la coller ailleurs (email, document...).
ℹ️ Sources : MY-IA indique toujours d'où vient l'information. Si aucune source n'est affichée, c'est une réponse basée sur ses connaissances générales.
4

Étape 4 : Astuces pour de meilleures réponses

Plus votre question est précise, meilleure sera la réponse. Voici quelques conseils :

Soyez spécifique

❌ Trop vague✅ Mieux formulé
"congés" "Quelle est la procédure pour poser des congés payés ?"
"le projet" "Quel est l'état d'avancement du projet Alpha ?"
"budget" "Quel est le budget marketing prévu pour 2026 ?"
"contact" "Qui est le contact principal chez le client Dupont SA ?"

Précisez le contexte

  • Période — "Quelles sont les ventes du premier trimestre 2025 ?"
  • Département — "Quelle est la procédure au service comptabilité ?"
  • Document — "Dans le rapport annuel, quels sont les objectifs ?"
  • Client/Projet — "Quelles sont les conditions du contrat Acme Corp ?"

Demandez le format souhaité

Liste à puces
"Liste-moi les étapes pour..."
Résumé
"Résume en 3 points..."
Tableau
"Présente sous forme de tableau..."
Comparaison
"Compare les options A et B..."

Posez des questions de suivi

MY-IA se souvient du contexte de la conversation. Vous pouvez enchaîner :

Question initiale
"Quelle est la procédure de remboursement ?"
Question de suivi
"Et quel est le délai ?" — MY-IA comprend que vous parlez du remboursement
Précision
"Qui dois-je contacter si c'est urgent ?" — Toujours dans le même contexte

Étape 5 : Fonctions avancées

Une fois à l'aise avec les bases, explorez ces fonctionnalités supplémentaires.

Mode vocal 🎤

Dictez vos questions au lieu de les taper :

  1. Cliquez sur l'icône micro 🎤
  2. Autorisez l'accès au micro si demandé
  3. Parlez clairement votre question
  4. Cliquez à nouveau pour arrêter l'enregistrement
  5. Vérifiez la transcription et envoyez

Joindre un document 📎

Posez des questions sur un document spécifique :

  1. Cliquez sur l'icône pièce jointe 📎
  2. Sélectionnez un fichier (PDF, Word, Excel...)
  3. Posez votre question, par exemple : "Résume ce document"

Changer de mode

Selon votre entreprise, différents modes peuvent être disponibles :

ModeUtilisation
GénéralQuestions sur tous les documents de l'entreprise
RHQuestions spécifiques aux ressources humaines
CommercialInformations produits, tarifs, clients
TechniqueDocumentation technique, procédures IT

Pour changer de mode, cliquez sur le sélecteur en haut de la zone de chat.

Gérer vos conversations

  • Renommer — Cliquez sur le titre d'une conversation pour lui donner un nom explicite
  • Supprimer — Survolez une conversation et cliquez sur 🗑️
  • Rechercher — Utilisez la barre de recherche pour retrouver une ancienne conversation
