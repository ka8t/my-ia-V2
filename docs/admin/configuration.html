Accès à l'administration — Section 1

URL d'accès

L'interface d'administration est accessible à l'adresse :

https://votre-serveur:8081
⚠️ Sécurité : L'interface admin doit être accédée uniquement par les administrateurs. En production, limitez l'accès par IP ou VPN si possible.

Modèle IA — Section 3

Accédez aux paramètres via Configuration > Modèle IA.

Fournisseur LLM

📦 Ollama

  • Recommandé pour la plupart des cas
  • Installation simple
  • Nombreux modèles disponibles
  • Gestion GPU automatique

⚙️ llama.cpp

  • Performant sur CPU
  • Contrôle fin des paramètres
  • Format GGUF requis
  • Configuration manuelle

Modèles disponibles

ModèleTailleVRAM requiseUsage recommandé
Mistral 7B 4 Go 6 Go Généraliste, rapide, bon français
Llama3 8B 5 Go 8 Go Très performant, multilingue
Qwen2 7B 4 Go 6 Go Excellent sur les données structurées
Llama3 70B 40 Go 48 Go Qualité maximale (GPU puissant requis)

Paramètres de génération

ParamètrePlageEffetRecommandé
Température 0.0 - 1.0 Créativité des réponses 0.3 (factuel) à 0.7 (créatif)
Top-K (RAG) 1 - 20 Nombre de passages consultés 5 - 10
Max tokens 256 - 4096 Longueur max des réponses 1024 (détaillé), 512 (concis)
Top-P 0.0 - 1.0 Diversité des mots choisis 0.9

Modèle d'embeddings

Le modèle d'embeddings transforme le texte en vecteurs pour la recherche :

  • nomic-embed-text — Recommandé, bon compromis qualité/vitesse
  • mxbai-embed-large — Meilleure qualité, plus lent
  • all-minilm — Léger, rapide, pour CPU
⚠️ Réindexation requise : Changer de modèle d'embeddings nécessite de réindexer tous les documents. Cette opération peut prendre du temps.

Inscription des utilisateurs

🔓 Inscription ouverte
N'importe qui peut créer un compte. Utile pour les tests ou accès public limité.
📧 Sur invitation
Seuls les utilisateurs invités par email peuvent s'inscrire. Recommandé en entreprise.
🏢 Domaines autorisés
Seuls les emails @entreprise.com peuvent s'inscrire. Sécurité renforcée.

Modes de conversation — Section 5

Les modes permettent de personnaliser le comportement de l'IA selon le contexte d'utilisation.

Créer un mode

1. Accéder aux modes
Configuration > Modes > + Nouveau mode
2. Définir l'identité
Nom, description, icône
3. Configurer le prompt système
Instructions pour l'IA
4. Associer les collections
Quels documents consulter
5. Activer le mode
Le rendre disponible aux utilisateurs

Exemples de prompts système

💼 Mode RH
"Tu es un assistant RH bienveillant. Réponds de manière professionnelle et empathique. Cite toujours les références légales (Code du travail) quand c'est pertinent. Si tu ne connais pas la réponse, oriente vers le service RH."
📊 Mode Commercial
"Tu aides les commerciaux à trouver des informations produits. Sois concis et factuel. Donne les prix, disponibilités et caractéristiques techniques. Suggère des produits complémentaires quand c'est pertinent."
⚙️ Mode Technique
"Tu es un expert technique. Réponds avec précision et détail. Utilise la terminologie technique appropriée. Fournis des exemples de code ou de commandes si nécessaire. Cite les versions et compatibilités."

Paramètres du mode

ParamètreDescription
Collections associéesDocuments accessibles dans ce mode
TempératurePeut surcharger la valeur globale
VisibilitéTous les utilisateurs ou certains rôles
Mode par défautSélectionné automatiquement pour les nouveaux utilisateurs

Collections de documents — Section 6

Les collections organisent vos documents par thème, département ou usage.

Créer une collection

1. Accéder aux collections
Documents > Collections > + Nouvelle collection
2. Définir l'identité
Nom, description
3. Choisir la visibilité
Publique (tous) ou Privée (sélection)
4. Ajouter des documents
Upload ou sources externes

Types de collections

🌐 Publique

  • Accessible à tous les utilisateurs
  • Documents officiels de l'entreprise
  • Procédures, règlements, catalogues

🔒 Privée

  • Accessible à des utilisateurs spécifiques
  • Documents confidentiels
  • Données sensibles par département

Corpus (regroupement)

Les corpus permettent de regrouper plusieurs collections pour une recherche élargie :

  • Recherche multi-collection — Une question peut chercher dans plusieurs collections à la fois
  • Cohérence thématique — Regroupez "RH Procédures" + "RH Légal" dans un corpus "RH"
  • Modes de conversation — Associez un corpus à un mode pour un contexte riche

Gestion des documents

ActionDescription
⬆️ UploadGlissez-déposez ou sélectionnez des fichiers (PDF, Word, Excel...)
🌐 Source webIndexez les pages d'un site internet
🔗 Source APIConnectez une API REST pour des données dynamiques
🔄 RéindexerReconstruire l'index après modification
🗑️ SupprimerRetirer un document (supprime aussi l'index)
💡 Bonnes pratiques : Organisez vos collections par thème métier (RH, Commercial, Technique) plutôt que par type de document. Cela facilite l'association aux modes.
