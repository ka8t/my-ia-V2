Resume — Section 1

MY-IA est une application de chatbot RAG 100% locale. Elle ingere des documents, les indexe dans une base vectorielle, puis enrichit les reponses du chat via retrieval. Aucune donnee n'est envoyee a des services externes.

🔒 Privee
Traitement et stockage sur l'infrastructure locale.
🧠 RAG
Reponses contextualisees a partir des documents.
⚡ Temps reel
Streaming des reponses dans l'interface.
🧰

Fonctionnalites — Section 5

  • Chat RAG — Reponses contextualisees avec sources.
  • Multi-formats — PDF, Office, images (OCR), Markdown.
